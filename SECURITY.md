# Security policy

Only the current development branch is maintained during the experimental alpha. There is no security support promise for older snapshots or third-party builds.

Please use the repository’s **Security → Advisories → Report a vulnerability** button for private reports when enabled: https://github.com/lukepoo101/stardew-mod-manager/security/advisories/new

If private reporting is unavailable, open an issue requesting a private contact route **without exploit details or sensitive data**. Do not publish credentials, private paths or user files. Include affected commit, impact and a minimal synthetic reproduction in the private report. No response-time guarantee is made for this volunteer project.

Archive checks protect the installation workflow; they do not sandbox executable mods. Only install trusted mods. Report path escapes, unintended deletion, incorrect process signalling and recovery/data-loss bugs as security-sensitive issues.
